# Panqué Bimbo Demand Dashboard

Interactive dashboard for the Challenge Market Solutions (Periodo 3, Tec de Monterrey) with Grupo Bimbo.

- Survey: 599 valid answers from people aged 25 to 35 in Mexico.
- Dynamic charts by segment, color-scale scorecard and Chi-square results.
- Single static page: open `index.html` in any browser.
